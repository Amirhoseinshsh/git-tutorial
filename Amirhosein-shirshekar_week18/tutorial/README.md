# 📇 لیست مخاطبین

یک اپلیکیشن ساده مدیریت مخاطبین با React. فرم‌ها با **React Hook Form** مدیریت شده و اعتبارسنجی با **Yup** انجام می‌شود.

## 🖼 اسکرین‌شات

(اینجا یک اسکرین‌شات از پروژه بگذارید)

## ✨ قابلیت‌ها

- افزودن، ویرایش و حذف مخاطب
- جستجو بر اساس نام یا شماره
- اعتبارسنجی فرم با Yup
- کامپوننت `FormInput` قابل استفاده مجدد
- ذخیره مخاطبین در localStorage

## 🛠 تکنولوژی‌ها

React · Vite · React Hook Form · Yup

## 🚀 نحوه اجرا

```bash
git clone <repo-url>
cd contact-list-simple
npm install
npm run dev
```

## 📁 ساختار پروژه

```
src/
├── components/
│   ├── FormInput.jsx    # input قابل استفاده مجدد
│   ├── ContactForm.jsx  # فرم افزودن و ویرایش
│   └── ContactList.jsx  # نمایش لیست
├── schemas/contactSchema.js  # قوانین yup
├── App.jsx
└── main.jsx
```
