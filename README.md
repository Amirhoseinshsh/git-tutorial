# Week 13 Mini Project — React Tabs

A responsive tab interface built with React and CSS, without UI/component libraries.

## Features
- Four clickable tabs that change the content
- Persists the last selected tab using localStorage
- Responsive layout and accessible tab attributes

## Run
This single-page demo loads React and React DOM as browser ES modules from esm.sh, so an internet connection is needed. Open `index.html` through a static web server or publish this folder with GitHub Pages.
