# دفتر من Pro — مدیریت ارتباطات

یک پروژه آموزشی React برای مدیریت مخاطبان با رابط فارسی و راست‌چین.

## امکانات
- افزودن و ویرایش مخاطب با اعتبارسنجی فرم
- جست‌وجو بر اساس نام، نام خانوادگی، ایمیل، تلفن و شرکت
- فیلتر گروه‌ها و علاقه‌مندی‌ها
- انتخاب چند مخاطب و حذف گروهی با تأیید
- حذف تکی با پنجره تأیید
- یادداشت و تاریخ پیگیری برای هر مخاطب
- شمارنده‌های داشبورد
- ذخیره خودکار داده‌ها در `localStorage`
- خروجی پشتیبان JSON
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- بدون کتابخانه جانبی رابط کاربری یا آیکون

## اجرا
1. Node.js را نصب داشته باش.
2. در پوشه پروژه اجرا کن:
   ```bash
   npm install
   npm run dev
   ```
3. آدرسی که Vite در ترمینال نشان می‌دهد در مرورگر باز کن.

## ساختار
- `src/main.jsx`: نقطه ورود React
- `src/App.jsx`: منطق، stateها، فیلتر، فرم و عملیات مخاطبان
- `src/styles.css`: ظاهر و واکنش‌گرایی

## نکته برای ارائه
قبل از تحویل، کد را خط‌به‌خط مرور کن، متن‌ها و رنگ‌ها را مطابق سلیقه خودت تغییر بده و مطمئن شو می‌توانی کاربرد `useState`، `useEffect`، `useMemo`، `map`، `filter` و اعتبارسنجی فرم را توضیح بده. اطلاعات اولیه نمونه هستند و می‌توانی آن‌ها را عوض کنی.
